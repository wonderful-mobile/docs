# Wonderful Mobile Docs

Documentation for [Wonderful Mobile](https://www.techtransthai.org/core/wonderful-mobile/),
a TechTransThai project that builds custom kernels for Android phones and
publishes the tools and patches behind them.

## Wonderful Kernel

Custom kernels built from the phone maker's source code.

- [About Wonderful Kernel](wonderful-kernel/index.md): what it is, devices and variants
- [Install](wonderful-kernel/install.md): first-time install
- [Upgrade](wonderful-kernel/upgrade.md): new releases, switching variants, firmware updates
- [Root managers](wonderful-kernel/root-managers.md): KernelSU, KernelSU-Next, SukiSU and SUSFS
- [Tweaks](wonderful-kernel/tweaks.md): every change compared to the stock kernel
- Devices: [Samsung Galaxy A23 5G](wonderful-kernel/samsung-a23xq.md)
