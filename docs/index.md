## What is Wonderful?

<p class="lead">Wonderful Mobile is an open-source project by TechTransThai. We take the kernel source that phone makers publish, clean it up, tune it, and give it back as something anyone can install or build on.</p>

## What the kernel does

<p class="lead">Every change keeps your phone's own drivers working. We never overclock or undervolt.</p>

<div class="card-grid">
<div class="card">
<span class="icon">⚡</span>
<h3>Smoother</h3>
<p>Built with Clang at -O3, tuned for the phone's CPU, with responsive scheduler settings.</p>
</div>
<div class="card">
<span class="icon">🔋</span>
<h3>Better battery</h3>
<p>Power-efficient background work and the schedutil CPU governor by default.</p>
</div>
<div class="card">
<span class="icon">🌐</span>
<h3>Faster networking</h3>
<p>BBR congestion control with fq_codel, for lower lag on busy or slow connections.</p>
</div>
<div class="card">
<span class="icon">🔓</span>
<h3>Root, your choice</h3>
<p>KernelSU-Next or SukiSU built in, optional SUSFS, or no root at all.</p>
</div>
</div>
